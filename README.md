# 🍽️ Zomato Restaurant Data Analysis

## 📌 Overview
An interactive **Power BI dashboard** analyzing 9,000+ Zomato restaurant records to uncover insights across sales, orders, customers, cuisines, and delivery patterns. The dataset was cleaned and transformed using Power Query, resolving inconsistencies across 10+ fields, with 6+ KPIs designed using DAX measures.

## 🛠️ Tools Used
- Power BI Desktop
- Python (pandas) (data cleaning & transformation)
- DAX (KPI measures)
- SQL

## 📊 Dashboard Features
- **Overview page** with Total Sales, Total Orders, Total Customers, Restaurant count & Average Rating
- **Sales Analysis** — Sales by Restaurant, Sales by Month, Sales by Cuisine
- **Order Analysis** — Orders by Time of Day, Online vs Offline Orders
- Multiple views: Restaurant Analysis, Cuisine Analysis, Location Analysis, Customer Analysis, Ratings & Reviews, Delivery Analysis
- Interactive slicers for **City** and **Restaurant**

## 🔑 Key Insights
- 💰 **Total Sales: ₹73M** across **7K orders** from **42K customers**, with an average rating of **3.70**
- 🍛 **North Indian is the most preferred cuisine**, generating ₹3,729K in sales, followed closely by North Indian-Chinese fusion (₹3,476K)
- 🌙 **Night (30%) and Afternoon (25.6%) are peak ordering times**, while mornings see the weakest order volume
- 📱 **57% of orders are placed online vs. 43% offline** — showing the online channel is dominant
- 🏆 **Cafe Coffee Day** leads restaurant-wise sales at ₹0.153M, followed by Onesta and Just Bake
- 📈 Monthly sales remained fairly stable through the year, ranging between 5M–6M
